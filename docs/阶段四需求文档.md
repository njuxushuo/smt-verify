# 阶段四需求文档：Relation Semantics 与 Value Constraint Encoding

## 1. 阶段定位与总体目标

本项目继续严格遵循：

> **阶段用于规划开发顺序，源码按长期语义职责组织。**

阶段四不是新增一套“Stage 4 专属 relation 代码”，而是补齐项目中另一个长期核心语义对象：

> **single tensor 与 distributed tensors 之间的 Relation semantics。**

当前项目已经完成：

```text
Stage 1
Stage JSON
    ↓
StageSpec

Stage 2
StageSpec
    ↓
symbolic shape constraints
    ↓
ReducedShapeResult

Stage 2.5
OperatorSemantics
    ├── registry
    └── operator-specific shape semantics

Stage 3
ReducedShapeResult + ProgramSpec
    ↓
Program-level symbolic execution
    ↓
single / each-rank SymbolicTensor expressions
```

阶段三已经能够回答：

```text
single program 自己算了什么？
rank 0 program 自己算了什么？
rank 1 program 自己算了什么？
...
```

但它仍然不知道：

```text
single A 与 A0/A1 的值有什么关系？
single B 与 B0/B1 的值有什么关系？
single C 与 C0/C1 的值有什么关系？
```

阶段四的目标是：

```text
RelationSpec
    +
single/distributed SymbolicTensor
    ↓
RelationSemantics
    ↓
element-wise Z3 Bool constraints
```

当前正式支持：

```text
Replicate
Shard(dim)
Partial(sum)
```

阶段四结束后，系统应能够分别得到：

```text
input relation constraints
output relation constraints
```

为阶段五构造：

\[
R_{in}\land \neg R_{out}
\]

以及完整 Stage equivalence query 做准备。

注意：

> 阶段四只负责 relation encoding，不实现正式的 `PROVED / DISPROVED / UNKNOWN` Stage verifier API。

---

# 2. 阶段四的两个核心任务

阶段四包含两个同等重要的任务。

## 2.1 Relation value semantics

实现：

### Replicate

\[
X_r[i]=X_s[i]
\]

### Shard(dim=d)

对于 rank \(r\) 上 local index：

\[
(i_0,\dots,i_d,\dots,i_n)
\]

对应 global index：

\[
(i_0,\dots,rL_d+i_d,\dots,i_n)
\]

其中：

\[
L_d=local\_shape[d]
\]

因此：

\[
X_r[i]
=
X_s[i_0,\dots,rL_d+i_d,\dots,i_n]
\]

### Partial(sum)

\[
X_s[i]
=
\sum_{r=0}^{P-1} X_r[i]
\]

---

## 2.2 RelationSemantics 架构重构

当前 `src/shape_constraints.py` 中仍然直接包含：

```text
replicate shape semantics
shard shape semantics
partial shape semantics
shard divisibility
```

并通过：

```python
if relation.type == ...
```

分派。

阶段四必须建立统一：

```text
RelationSemantics
├── ReplicateRelation
├── ShardRelation
└── PartialRelation
```

并把 relation-specific symbolic shape semantics 从 `shape_constraints.py` 迁移到 relation class。

最终形成：

```text
OperatorSemantics
├── shape_constraints()
└── symbolic_execute()

RelationSemantics
├── shape_constraints()
└── value_constraints()
```

这是阶段四最重要的长期源码结构目标。

```python

    name: str

    def shape_constraints(
        self,
        relation: RelationSpec,
        single_shape: tuple[z3.ArithRef, ...],
        local_shapes: tuple[tuple[z3.ArithRef, ...], ...],

        raise NotImplementedError

    def value_constraints(
        self,

        single_tensor: SymbolicTensor,
```

```text
metaclass

```

# 10. `ReplicateRelation`

定义：

```python
class ReplicateRelation(RelationSemantics):
    name = "replicate"
```

---

## 10.1 Shape semantics

要求：

```text
len(local_shapes) == world_size
```

并对每个 rank：

```text
rank(single_shape) == rank(local_shape)
```

生成逐维：

\[
local_{r,d}=single_d
\]

即：

\[
shape(X_r)=shape(X_s)
\]

如果 rank 不一致：

```text
ShapeReductionError
```

---

## 10.2 Value semantics

运行时验证：

```text
len(local_tensors) == world_size
all local.shape == single_tensor.shape
relation.dim is None
relation.reduce_op is None
```

然后对每个 rank、每个 flattened element：

\[
X_r[i]=X_s[i]
\]

可以直接使用：

```python
zip(single_tensor.values, local_tensor.values)
```

生成 equality。

---

# 11. `ShardRelation`

定义：

```python
class ShardRelation(RelationSemantics):
    name = "shard"
```

---

## 11.1 Shape semantics

要求：

```text
relation.dim is int
0 <= relation.dim < rank
len(local_shapes) == world_size
```

对于每个 rank local shape：

非 shard 维：

\[
local_{r,k}=single_k
\]

shard 维：

\[
world\_size \times local_{r,d}=single_d
\]

并且只添加一次：

\[
single_d \bmod world\_size = 0
\]

因此原来：

```text
shape_constraints.py/_shard_divisibility_constraints
```

的职责必须完全迁移至 `ShardRelation.shape_constraints()`。

---

## 11.2 Value semantics

当前固定语义：

> regular contiguous equal-size shard，`distributed_tensors[r]` 对应 shard order 中的 rank `r`。

要求：

```text
len(local_tensors) == world_size
all local tensors rank == single rank
non-shard dimensions equal
single shard dimension == world_size * local shard dimension
all ranks local shape identical
relation.reduce_op is None
```

---

## 11.3 Index mapping

使用：

```python
itertools.product
```

遍历 local tensor 的全部 multi-dimensional index。

例如：

```python
for local_index in product(
    *(range(extent) for extent in local_tensor.shape)
):
    ...
```

对于 rank `r`：

```python
global_index = list(local_index)
global_index[d] = (
    r * local_tensor.shape[d]
    + local_index[d]
)
```

然后生成：

```python
local_tensor.at(local_index)
==
single_tensor.at(tuple(global_index))
```

---

## 11.4 Shard dim=0 示例

```text
single X [4,2]
world_size=2

rank0 X0 [2,2]
rank1 X1 [2,2]
Shard(dim=0)
```

映射：

```text
X0[0,0] == X[0,0]
X0[1,1] == X[1,1]

X1[0,0] == X[2,0]
X1[1,1] == X[3,1]
```

---

## 11.5 Shard dim=1 示例

```text
single X [2,4]
world_size=2

rank0 X0 [2,2]
rank1 X1 [2,2]
Shard(dim=1)
```

映射：

```text
X0[0,0] == X[0,0]
X0[0,1] == X[0,1]

X1[0,0] == X[0,2]
X1[0,1] == X[0,3]
```

该测试必须存在，避免把 flat offset 与 shard dimension mapping 混淆。

## 12.2 Value semantics

运行时验证：

```text

relation.reduce_op == "sum"
len(local_tensors) == world_size
all local.shape == single_tensor.shape
```

对于每一个 flattened element index `i`：

\[

=

```python

    [local.values[i] for local in local_tensors]

```

生成：

```python
single.values[i] == z3.Sum(...)
```


这不视为重复实现。

# 18. Input relation 只能约束真实 program inputs

这是阶段四新增的重要 soundness contract。

对于：

```text
stage.input_relations
```

每一个 relation：

single tensor 必须属于：

```python
symbolic.single.input_names
```

并且 rank `r` 上对应 tensor 必须属于：

```python
symbolic.distributed[r].input_names
```

否则：

```text
RelationEncodingError
```

例如：

```text
input_relations[0]
```

若引用一个由 MatMul 产生的 intermediate tensor：

```text
C
```

不能把：

```text
C 与 C0/C1 的关系
```

偷偷作为 proof premise。

这会破坏后续 Stage verifier 的语义。

---

# 19. Output relation 的范围

`stage.output_relation`：

> 可以引用任意 symbolic execution 后存在的 declared tensor。

不强制必须是 produced tensor。

原因：

无-op identity stage 可能直接把 input tensor 作为 output boundary。

因此只要求：

```text
tensor exists in SymbolicStageResult
```

不要求：

```text
tensor not in input_names
```

# 21. `encode_stage_relations`

提供阶段四高层入口：

```python
def encode_stage_relations(
    stage: StageSpec,
    symbolic: SymbolicStageResult,

```

```text

```


```text

    ↓

    ↓
```

# 23. 标准 MatMul + Shard → Partial case

输入：

```text
input/matmul_shard_to_partial.json
```

阶段二：

```text
Single:
A [1,2]
B [2,1]
C [1,1]

Rank 0/1:
A_r/B_r/C_r [1,1]
```

阶段三：

```text
single C
=
single__A__v0 * single__B__v0
+
single__A__v1 * single__B__v1

C0
=
rank0__A0__v0 * rank0__B0__v0

C1
=
rank1__A1__v0 * rank1__B1__v0
```

---

## 23.1 Input relation A — Shard(dim=1)

必须编码：

```text
rank0__A0__v0 == single__A__v0
rank1__A1__v0 == single__A__v1
```

---

## 23.2 Input relation B — Shard(dim=0)

必须编码：

```text
rank0__B0__v0 == single__B__v0
rank1__B1__v0 == single__B__v1
```

---

## 23.3 Output C — Partial(sum)

必须编码：

\[
single.C[0,0]
=
rank0.C0[0,0]
+
rank1.C1[0,0]
\]

即 constraint 左右都可以是阶段三已经产生的复杂 Z3 arithmetic expression。

# 52. 最终验收标准

阶段四完成后必须能够：

```text
StageSpec
    +
ReducedShapeResult
    +
SymbolicStageResult
        ↓
input RelationSpec
        ↓
Replicate / Shard / Partial RelationSemantics
        ↓
input Z3 Bool constraints

output RelationSpec
        ↓
RelationSemantics
        ↓
output Z3 Bool constraints
```

标准 case 必须得到：

```text
Input:
rank0 A0 == single A shard 0
rank1 A1 == single A shard 1

rank0 B0 == single B shard 0
rank1 B1 == single B shard 1

Output:
single C == rank0 C0 + rank1 C1
```

其中 C/C0/C1 已经是阶段三 MatMul expressions。

标准 integration sanity test：

```text
input relation constraints
AND
NOT(output relation constraints)
```

必须为：

```text
UNSAT
```

错误 candidate 的 sanity test 必须能够得到：

```text
SAT
```

同时：

```text
shape reduction结果不变
symbolic execution结果不变
所有旧测试继续通过
```

阶段四最终交付的是：

> **一个统一的 RelationSemantics 系统：集中承载 Replicate、Shard、Partial(sum) 的 symbolic shape/value semantics，并把 Stage 的 input/output tensor relations 编码为稳定、可组合的 Z3 Bool constraints，为阶段五完整 equivalence verifier 提供前提与证明目标。**
