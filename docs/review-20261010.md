# Ordered IndexPhi extension review

Date: 2026-10-10. Pre-implementation checkpoint: `3d11079`.

## Scope

The extension supports distinct-family IndexPhi terms on the same tensor
dimension, applied in supplied local-to-global order. It does not change
operator semantics, input JSON contents, Partial(sum) semantics or physical
shape reduction policy. One term per family and at most one Partial remain.

Validation checks every level's ranges and injectivity, rank-specific adjacent
extents, and actual local/global endpoints. Normalization composes interval
functions, splitting pieces at intermediate boundaries and merging only
contiguous equal translations. SMT forward/inverse and Partial common-domain
checks consume the final map. Reports retain the original levels and display
the composed maps separately.

## Independent review

The exposed model overrides did not include the requested "6 astra" name.
The reviewer was a separate sub-agent inheriting the current model; no claim
is made that the unavailable override was selected. The reviewer edited no
repository files and reported no findings in the extension's requested scope.

Independent probes reported:

- 7,285 interval compositions matched an element-wise oracle, including piece
  reordering, boundary intersections, image gaps and canonicalization.
- Three-level chain and flat-map proof comparisons produced 50 expected
  PROVED and 50 expected DISPROVED results, including interleaved dimensions,
  rank-specific intermediate extents and Partial.
- The eight-rank CP/SP/DP AllGather proved, while a structurally legal wrong
  output map disproved.
- Follow-up review confirmed report level labels, extent values and final maps,
  plus codec preservation of term/map/piece order. All 30 focused composition,
  codec and reporting tests passed.

The sweep's interval count grows additively per composition under validated
injectivity. Sorting and sweeping use ranges, not individual tensor elements.
This review is engineering evidence, not a formal proof of the verifier itself.

## Final validation

- 57 unittest tests passed. The new test module includes 180 seeded randomized
  three-level map compositions in addition to named deterministic regressions.
- All 11 repository inputs return PROVED under ORIGINAL_SHAPES_EXACT_REAL.
- All 52 SMT queries extracted from the 11 generated demo.txt reports replay
  as UNSAT, and every report's canonical input hash matches its input.
- All input JSON files are byte-identical to checkpoint `3d11079`, including
  the five protected MLP JSON files.
- Ruff F checks, formatting, compilation, import-direction tests, documentation
  links, bilingual JSON examples and `git diff --check` passed.

Negative tests cover a valid wrong output map, source/intermediate/final extent
mismatches on a nonzero rank, reversed chains, noncommuting equal-size maps,
cross-piece boundaries, malformed intermediate maps, composition to identity,
uneven local shapes and Partial with permuted storage order.

Reports are human-readable audit artifacts with replayable queries, not
independently checked proof certificates. Conclusions are conditional on input
relations and the declared real/shared-function model. General floating-point,
dynamic indexing, repeated family IDs and multiple Partial composition remain
outside this implementation.
